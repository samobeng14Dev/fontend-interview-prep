# Frontend Interview Handbook

A personal, 10-part reference guide for frontend technical interviews — covering core web fundamentals through SEO/AEO/GEO, system design, and behavioral prep.

Built while prepping for a frontend (with full-stack background) remote role, with extra focus on SEO/AI-search-visibility topics relevant to search-marketing companies.

## Contents

| Part | Topic |
|---|---|
| 1 | HTML, CSS, JavaScript |
| 2 | TypeScript & React Fundamentals |
| 3 | Advanced React & Next.js (Rendering, RSC, App Router) |
| 4 | SEO, Technical SEO, AEO & GEO |
| 5 | Performance, Core Web Vitals & Browser Internals |
| 6 | APIs, React Query, State Management & Security |
| 7 | Testing, Git, CI/CD & Deployment |
| 8 | Frontend System Design |
| 9 | Behavioral, Company Fit & Mock Interview |
| 10 | Rapid Revision — 100 Most Likely Questions |

Each topic includes the question, a full answer, why interviewers ask it, common follow-ups, and code examples where relevant.

## How to Use

- Read part by part, or jump straight to **Part 10** for a quick pre-interview refresher.
- Try answering each question out loud before checking the written answer.
- Fill in your own project details/numbers wherever a section prompts for a personal example.
